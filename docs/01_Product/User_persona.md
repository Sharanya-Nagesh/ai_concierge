# User Personas

> **Document Purpose**
>
> This document defines the primary users of AI Concierge, their goals, challenges, and how the platform addresses their needs. These personas guide product decisions, feature prioritization, and user experience design.

---

# Why User Personas?

Every software product should be designed around its users—not around technology.

AI Concierge aims to serve a diverse audience with varying goals. By defining clear user personas, we ensure that every feature solves a meaningful problem for a real user.

These personas are fictional but represent realistic groups of users.

---

# Primary Persona 1: Student

## Profile

**Name:** Asha

**Age:** 21

**Occupation:** Undergraduate / Postgraduate Student

**Technical Knowledge:** Beginner to Intermediate

---

✅ Explain concepts in preferred language

# Common User Needs

Regardless of profession, most users want:

- Natural conversations
- Personalized responses
- Memory across sessions
- Easy document search
- Multilingual communication
- Trustworthy answers
- Simple interface

---

# Supported Languages

Version 1 officially supports:

- English
- Hindi
- Kannada
- Tamil
- Telugu

Users may naturally mix languages within the same conversation.

Example:

> "Explain this PDF in Kannada."

> "Kal ka study plan bana do."

---

# Accessibility Goals

AI Concierge should be usable by:

- Beginners
- Non-technical users
- Students
- Elderly users
- Multilingual users

The interface should remain simple, intuitive, and accessible.

# Key Insights

From these personas, several design priorities emerge:

- Personalization is more valuable than generic responses.
- Users want AI to remember context across sessions.
- Document understanding is a core capability.
- Multilingual communication improves accessibility.
- Simplicity is essential for adoption.

---

# Summary

AI Concierge is designed for users who interact with information daily. Whether studying, researching, teaching, or working, users need an assistant that remembers context, understands their documents, communicates naturally, and adapts to their goals over time.

These personas will guide future design and engineering decisions throughout the project.
